# Knowledge library

> [!note] Example content for the atlas prototype. Replace it with your own.

Everything you need to do a task the team's way: templates to copy, checklists to follow, guides that explain how and why, and decision records that say what we chose.

| Folder | What goes in it | Example |
|---|---|---|
| `templates/` | Starting points you copy | `how-to-guide.md` |
| `checklists/` | Steps you tick through | `code-review.md` |
| `guides/` | How and why, in prose | `team-charter.md` |
| `decisions/` | What we chose and why, numbered | `0001-gitlab-structure.md` |

## Naming
- Lower-case, hyphenated file names: `code-review.md`, not `Code Review Checklist v2 FINAL.md`.
- Decision records are numbered in order and never renumbered.
- Each document says who owns it and when it was last reviewed.
