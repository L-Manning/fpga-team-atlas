# Raising a request on the notice board

> [!note] Example content for the atlas prototype. Replace it with your own.

Can't find the template, checklist or guide you need? Ask for it. Requests appear on the atlas notice board, and the most-wanted ones become tasks.

1. Create a note in `roadmap/requests/` from the **request** template.
2. Write the question the way you'd ask a colleague: “How should I name branches?”
3. If someone has already asked, add your name to its `plus_ones` instead.

The lead triages requests every week. Each one is mapped to an existing task, turned into a new task, or answered and closed.
