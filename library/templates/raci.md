# Roles and responsibilities (RACI)

> [!note] Draft in review. Example content for the atlas prototype.

R = does the work, A = accountable for the outcome, C = consulted, I = kept informed.

| Activity | Lead | Design engineer | Verification engineer | Tools owner |
|---|---|---|---|---|
| Task breakdown | A | R | R | I |
| Code review | A | R | R | C |
| Release to PDM | A | C | C | R |
| CI and runner admin | I | C | C | R/A |
| Onboarding a new starter | A | R | R | C |
